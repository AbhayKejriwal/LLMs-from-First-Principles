§6 failure modes · interpretability — space turns the dial

We can find one concept inside — and turn it up.

Researchers isolated a single internal feature that fires on one concept — the Golden Gate Bridge. Crank that feature's strength up, and the model can't stop steering everything toward it. Move the dial:
bridge featurestrength 0
▸ what does "a feature" mean?

Inside the weights, concepts aren't stored in one neuron — they're directions in a high-dimensional space. Interpretability work pulls these directions out as named "features" (a bridge, a bug in code, sycophancy). You can read them, and you can amplify one. We know the mechanics exactly; reading the trained weights is the hard, unfinished part.

If the model isn't smarter — just looped — what's the ceiling?

one take — after they answerThe ceiling isn't the model's raw intelligence — it's the harness: which tools it can call, how fast errors compound, how much context it can hold before it forgets. Better scaffolding moves the ceiling more than a slightly smarter model does.
